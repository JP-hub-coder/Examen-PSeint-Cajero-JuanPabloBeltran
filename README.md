# 🏧 Examen-PSeint-Cajero-JuanPabloBeltran

Proyecto desarrollado en **PSeInt** que simula el funcionamiento básico de un cajero automático mediante pseudocódigo y lógica estructurada.

Este ejercicio fue realizado como parte de una evaluación académica enfocada en algoritmos, estructuras de control y resolución de problemas utilizando PSeInt.

---

# 📌 Descripción

El proyecto implementa un sistema de cajero automático capaz de realizar operaciones básicas mediante pseudocódigo, aplicando conceptos fundamentales de programación.

El objetivo principal es fortalecer habilidades de lógica computacional utilizando:

- Variables
- Condicionales
- Ciclos
- Operaciones matemáticas
- Validaciones
- Estructuras de control

---

# 🎯 Objetivos del Proyecto

- Simular un cajero automático
- Aplicar lógica de programación
- Utilizar estructuras condicionales
- Validar entradas de usuario
- Practicar algoritmos en PSeInt
- Resolver problemas mediante pseudocódigo

---

# 🛠 Tecnologías Utilizadas
